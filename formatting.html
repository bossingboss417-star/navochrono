HTML Text Formatting

Explanation of Formatting Tags

Bold text uses the b tag to make text bold without extra importance.

HTML stands for HyperText Markup Language. The strong tag defines text with strong importance, while the em tag defines emphasized text.

Italic text uses the i tag to display text in italics.

Underlined text uses the u tag to add an underline to text.

Highlighted text uses the mark tag to highlight text for reference.

Small text uses the small tag to define smaller text.

The del tag represents deleted text, and the ins tag represents inserted text.

The sub tag defines subscript text, while the sup tag defines superscript text.
